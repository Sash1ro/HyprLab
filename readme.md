# HYPERLAB

**My approach to a comfortable Hyprland Setup**

## Features

- Themes switcher
- Wallpapers switcher
- Complete Rofi menu for almost everything
- Neovim
- And more...

## Requirements

- Hyprland and its dependencies
- an Arch Distro (for now)

All other dependencies will be installed automatically.

## Installation

download the installation script and run :

```
./install.sh
```

restart after the installation

The script will:

- Install missing dependencies

- Backup your existing configs

- Install the HYPERLAB configuration

- Set default themes and wallpapers

- Restart your graphical session (optional)
